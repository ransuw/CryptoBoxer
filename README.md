# CryptoBoxer

CryptoBoxerは、画像、動画、PDF、音声、テキストなどの個人ファイルそのものを暗号化し、macOS本体、外付けストレージやクラウドストレージなど、好きな場所に安全にファイルを保存するためのmacOS向け暗号化管理ツールです。
Appleの `CryptoKit` を用いた強力な暗号化（AES-GCM）と、Argon2idを用いてパスワードから暗号化キーを生成する堅牢な機能を備えています。

> [!WARNING]
> **⚠️ セキュリティ上の条件**
> 本アプリをご利用の際は、macOSのディスク暗号化機能である **FileVault を必ず有効（ON）** にしてください。
> 閲覧時の一時的な復号やOSの仮想メモリ機構によるメモリ情報のスワップが発生した際に、ディスク全体が暗号化されていないと、一時的な平文データや鍵情報が物理ディスク上に残るリスクがあります。

---

## 💡 主な機能 (Features)

- **強力な暗号化・復号化 (AES-256-GCM)**: Appleの安全な暗号化ライブラリ `CryptoKit` を使用し、ファイルデータをAES-256-GCMで暗号化して保存します。改ざんされた暗号化済みのファイルデータを復号しようとした場合、復号化に失敗します。
- **堅牢な鍵生成 (Argon2id)**: パスワードをそのまま使用するのではなく、Argon2idを用いることで、GPUなどを利用したオフラインの総当たり攻撃に対して耐性を持つ暗号化キーを生成します。
- **ファイルの匿名化機能**: 暗号化保存時にファイル名をUUIDに自動変換するオプションを搭載。ファイル名から中身を推測されるのを防ぎます。
- **元ファイルの自動削除**: ファイルの暗号化保存が成功した際、元のファイル（プレーンデータ）を自動的に削除してストレージをクリーンに保つことができます。
- **スムーズな一時プレビュー**: 暗号化されたファイル（鍵アイコン）をクリックすると、一時フォルダ（`tmp`）に復号されたファイルが生成され、Finderでその場所が開きます。
- **各種エクスポート機能**:
  - **一括書き出し (暗号化)**: 暗号化されたファイルのまま指定したフォルダへコピー（バックアップ）します。
  - **一括書き出し (復号化)**: 暗号化ファイルをパスワードを用いて復号した状態で指定したフォルダへ一括保存します。
- **データの完全消去**: アプリ内からワンクリックで、CryptoBoxerに保存されているすべての暗号化データおよびプレビュー用一時フォルダの内容をクリーンアップできます。

## 📂 データの保存先 (Data Locations)

本アプリが使用するデータは、macOS標準のアプリケーションサポートフォルダ内に保存されます。

| フォルダ名  | パス                                               | 用途                                                       |
| :---------- | :------------------------------------------------- | :--------------------------------------------------------- |
| **storage** | `~/Library/Application Support/CryptoBox/storage/` | 暗号化されたファイル（実データ）が格納される場所           |
| **tmp**     | `~/Library/Application Support/CryptoBox/tmp/`     | プレビュー閲覧時に一時的に復号されたファイルが置かれる場所 |

## 🚀 使い方 (Usage)

### インストール方法

GitHubのReleaseをご確認ください。

### 1. パスワード設定（初回または変更時）

1. メイン画面の **「パスワード設定／鍵生成」** をクリックします。
2. 暗号化および復号に使用するパスワードを入力します。
3. *誤入力を防止したい場合*は、「パスワード(再)を入力する」のトグルをONにし、確認用パスワードを入力します。
4. **「設定」** ボタンを押すと、入力したパスワードからキーが生成され、メモリ上に保持されます。
5. Argon2idの試行回数を変えたい場合は 設定する前にあらかじめ「▲」「▼」 のボタンから変えてください。またソルトを変えたい場合は、テキスト文字を変更してください。

⚠️キーを生成するにあたって、パスワードや試行回数やソルトが少しでも違うと、全く異なるキーが生成されます。生成する際は間違いのないように、入力してください。間違ったキーで暗号化してしまうと、2度と復号化できなくなる恐れがあります。

⚠️キーの情報は、物理メモリ上またはストレージに存在します。アプリの使用を終えたら速やかにアプリのタスクを停止することを推奨します。

### 2. ファイルの暗号化

1. メイン画面の **「平文ファイル取り込み」** をクリックします。
2. 必要に応じて以下のオプションを設定します：
   - **ファイル名を匿名化する**: ONにすると、ファイル名が `UUID.<拡張子>` にリネームされて保存されます。
   - **元ファイルを削除する**: ONにすると、暗号化完了後にインポート元のファイルを削除します。
3. **「ファイルを選択」** ボタンを押し、暗号化したいファイルを選択します。

⚠️ファイルを暗号化してしまうと、そのファイルの作成日などのメタ情報が失われます。メタ情報が重要なファイルを暗号化する場合、ご注意ください。デジタルフォレンジックに関するファイルの暗号化は推奨しません。

⚠️セキュリティソフトの設定により、ファイルの削除ができないことがあります。その場合、手動で削除してください。

### 3. 暗号化ファイルの閲覧と管理

メイン画面の **「暗号化済みファイル一覧」** をクリックします。

- **一時プレビュー**:
  一覧の鍵アイコンのファイルをクリックすると、`tmp` フォルダに一時的に復号されたファイルが作成され、Finderでその場所が開きます。
- **フォルダを開く**:
  現在暗号化された実ファイルが保存されている `storage` フォルダをFinderで開きます。
- **暗号ファイル取込**:
  外部から既存の暗号化ファイルを直接 `storage` フォルダに追加インポートします。
- **一括書き出し（暗号化 / 復号化）**:
  保存されている全ファイルを一括で任意のフォルダにエクスポートします（暗号化したまま、または復号した状態を選択可能）。
- **全削除**:
  **「全削除」** ボタンを押すと、`storage` 内の暗号化ファイルと `tmp` 内の一時復号ファイルがすべて削除されます。

⚠️ファイルを閲覧するには復号キーが必要になります。パスワード設定で設定したキーが誤っていたり、キーを設定していないと、暗号化ファイルを復号できません。

⚠️暗号化済みのファイルが改ざんされていた場合、復号できません。（手動で改ざんし、復号できないことを確認済み）

⚠️セキュリティソフトの設定により、ファイルの削除ができないことがあります。その場合、手動で削除してください。

## 🛠️ 技術スタックとセキュリティ仕様 (Technical Details)

### 開発環境

- **対応OS**: macOS 26.2以降
- **言語**: Swift

  swift-driver version: 1.168.6 Apple Swift version 6.4.2 (swiftlang-6.4.2.1.9 clang-2100.4.1.1)

- **XCode**: Version 27.2
- **鍵導出アルゴリズム**: Argon2id
- **鍵導出ライブラリ**: [SwiftArgon2](https://github.com/mimiclone/argon2-swift)(MIT License)
  - 用途：Argon2idによるパスワードベースの鍵導出
  - ライセンス：MIT License
  - ソースコード：argon2-swift/
  - ライセンス文書：argon2-swift/LICENSE

- **暗号化手法**: AES-GCM (Authenticated Encryption with Associated Data)

### 推奨要件

- **セキュリティ前提条件**: macOSの **FileVault が有効（ON）** であること

### セキュリティ詳細

1. **Argon2id による鍵導出**

- パスワードとソルトを入力として、Argon2idを使用し、SymmetricKey（256-bit）を導出します。ただし、ソルトは任意に変更できるようになっています。
- Argon2idはメモリハード型の鍵導出関数（KDF）であり、メモリを大量に使用することで、GPUなどを利用したオフライン総当たり攻撃の効率を低下させます。
- 現在の設定値は、メモリ使用量 65536 KiB（64 MiB）、反復回数 30、並列度 4 です。ただし、反復回数は任意に変更できるようになっています。

2. **AES-GCM による認証付き暗号化**

- ファイルの暗号化には、AES.GCM.seal(\_:using:) を使用しています。
- 復号時には、AES.GCM.open(\_:using:) によって認証タグを検証します。
- 暗号ファイルなどが改ざんされている場合や、異なる鍵が使用された場合は認証に失敗し、復号できません。

3. **パスワードと鍵のファイル保存を行わない設計**

- アプリの起動中は、パスワードや生成された鍵がメモリ上に一時的に保持されます。
